# Security policy

Please report vulnerabilities privately to **security@layerhop.com**, or use GitHub's
"Report a vulnerability" button on the affected repository. Do not open a public issue,
discussion or pull request for a security problem.

Include the affected surface (web app, API, widget, SDK, CLI, MCP server, Telegram bot),
the version, steps to reproduce and the impact you observed. We acknowledge reports within
3 business days and keep you updated until a fix is released.

LayerHop is non-custodial: we never hold user funds or private keys, and our SDKs only build
*unsigned* transactions that the user's own wallet signs.
