# Contributing to LayerHop

Thanks for helping! Issues and pull requests are welcome on our public repositories.

1. **Search first.** Check existing issues before opening a new one.
2. **Keep PRs focused.** One change per pull request, with tests where it makes sense.
3. **Run the checks.** Each repository's README lists its install, test and build commands.
4. **Be kind.** We follow the [Code of Conduct](CODE_OF_CONDUCT.md).

The SDK repositories are exported from our main codebase. A maintainer applies accepted changes
upstream and the next sync brings them back, so your PR may be closed instead of merged. You
are still credited, and that is expected.

Security problems go to security@layerhop.com, not to issues. See [SECURITY.md](SECURITY.md).
