# Getting help

- **Docs:** <https://docs.layerhop.com> (quickstart, API reference, SDK guides)
- **Bugs and feature requests:** open an issue on the relevant repository, such as
  [layerhop-js](https://github.com/layerhop/layerhop-js/issues) or
  [layerhop-python](https://github.com/layerhop/layerhop-python/issues)
- **Integrations, partner fees and API limits:** dev@layerhop.com
- **Security issues:** never in public; see [SECURITY.md](SECURITY.md)

We never ask for private keys or seed phrases. Anyone who does is not LayerHop.
